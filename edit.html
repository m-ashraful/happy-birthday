এক বারের কাজ: গিটহাবের চাবি

এই পাতা থেকে লাইভ করতে গিটহাবের একটা চাবি (টোকেন) লাগবে। চাবিটা শুধু এই ব্রাউজারেই থাকবে, অন্য কোথাও যাবে না।

  1. নিচের বোতামে চাপ দিন, গিটহাবের পাতা খুলবে (m-ashraful হিসেবে লগইন থাকতে হবে)।
  2. Token name-এ যেকোনো নাম দিন, Expiration-এ পছন্দমতো সময় (যেমন ৯০ দিন)।
  3. Repository access → Only select repositories → happy-birthday বাছুন।
  4. Permissions → Contents → Read and write করুন।
  5. নিচে Generate token চাপুন। যে লেখাটা আসবে (github_pat_ দিয়ে শুরু), কপি করে এখানে বসান।
